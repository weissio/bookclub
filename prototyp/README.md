# Prototyp „Buch erfassen“

**Version 3 – Karteikarte** (10.10.2026). Design noch nicht von Arjen bestätigt.

- `buch-erfassen.dc.html` – Quelldatei des klickbaren Prototyps. Sie ist für den Design-Canvas in claude.ai geschrieben und läuft nicht direkt im Browser (sie braucht dessen Laufzeit `support.js`).
- Der Prototyp liegt live als privates Artifact in claude.ai.

## Ablauf

1. Scannen oder ISBN eintippen (Demo, Beispielbuch erfunden)
2. Lesestand stempeln (Pflicht)
3. Bei „Gelesen“: Sterne, Gefühle umkreisen, Lesefluss und Sprache per Lesebändchen, Tempo, Stärken markieren oder wellig unterstreichen, Nachhall / Wiederlesen / Autorin, eigene Worte
4. Bei „Abgebrochen“: Seite und Grund, keine Sterne
5. Rückseite: Exemplar (Format, Besonderheiten, Standort)
6. Ins Regal stellen → Zusammenfassung als Karteikarte
